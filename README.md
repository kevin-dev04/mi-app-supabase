#  Mi App con Supabase - Práctica de Laboratorio

Proyecto desarrollado para el Laboratorio de Programación Orientada a Objetos (POO). Esta aplicación demuestra la conexión entre un entorno local y una base de datos relacional en la nube.

## Tecnologías Utilizadas
* **Node.js** - Entorno de ejecución
* **Supabase** - Backend y Base de Datos (PostgreSQL)
* **JavaScript** - Lógica de conexión y consultas
* **Git/GitHub** - Control de versiones

## 🌟 Características Implementadas
- [x] Configuración inicial del proyecto con `npm`.
- [x] Conexión exitosa a Supabase mediante `@supabase/supabase-js`.
- [x] Inserción de datos desde el código.
- [x] Implementación de **Base de Datos Relacional**.
- [x] Consultas avanzadas con **JOIN** uniendo las tablas `estudiantes` y `materias` para generar reportes dinámicos.
